\# 🩸 Blood Bridge



A full-stack web application that connects blood donors with patients and manages blood donation camps.



\## 🌟 Features



\- 👤 User Registration \& Login with OTP verification

\- 🔍 Search donors by blood type

\- 🏕️ Blood donation camps tracking \& location

\- 📋 Donor management system

\- 📱 Responsive design

\## 🚀 How to Run Locally



1\. Clone the repository

```bash

&#x20;  git clone https://github.com/ankitdaila961-oss/Blood\_Bridge.git

```



2\. Install dependencies

```bash

&#x20;  npm install

```



3\. Setup environment variables

```bash

&#x20;  cp .env.example .env

&#x20;  # Fill in your database credentials in .env

```



4\. Run the server

```bash

&#x20;  node server.js

```



5\. Open browser and go to `http://localhost:3000`
